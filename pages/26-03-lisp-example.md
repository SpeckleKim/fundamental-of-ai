# 26-03. 작은 예제

이론은 책장 위에서 충분히 익었다. 이제 남은 건 손을 더럽히는 일이다. 거창할 필요는 없다. 화면 한구석에 작은 함수 하나를 짜놓고, 그것이 머릿속에서 한 단계씩 풀려나가는 광경을 지켜보는 일 — 그 경험이 읽기만 할 때와는 전혀 다른 이해를 데려온다. LISP로 작은 것을 직접 만들어 보자.

## 예제 1: 리스트 뒤집기

리스트를 거꾸로 만드는 함수를 떠올려 보자. 재귀로 생각하면 이렇다. 나머지(cdr)를 먼저 뒤집어 놓고, 떼어둔 첫 원소(car)를 그 맨 뒤에 슬쩍 붙인다.

```lisp
(defun 뒤집기 (lst)
  (if (null lst)
      nil                              ; 빈 리스트는 그대로
      (append (뒤집기 (cdr lst))        ; 나머지를 뒤집고
              (list (car lst)))))      ; 첫 원소를 뒤에 붙인다

(뒤집기 '(a b c d))   ; → (d c b a)
```

머릿속으로 한 걸음씩 따라가 보자. `(뒤집기 '(a b c))`는 `(뒤집기 '(b c))`의 결과 뒤에 `a`를 붙이는 일이고, 그 안쪽은 또 한 겹 더 들어간다. 끝까지 파고들었다가 빈 리스트에 닿는 순간, 함수는 방향을 바꿔 한 겹씩 되짚어 나온다. 종이 위에 직접 펼쳐보면, 재귀가 풀려나가는 그 리듬을 손끝으로 느끼게 된다.

## 예제 2: 멤버 찾기 (간단한 추론의 씨앗)

이번에는 어떤 원소가 리스트 안에 들어 있는지 확인하는 함수다.

```lisp
(defun 속하나 (x lst)
  (cond ((null lst) nil)               ; 빈 리스트엔 없다
        ((equal x (car lst)) t)        ; 첫 원소가 x면 있다!
        (t (속하나 x (cdr lst)))))      ; 아니면 나머지에서 찾는다

(속하나 'c '(a b c d))  ; → t
(속하나 'z '(a b c d))  ; → nil
```

이 단출한 함수가 실은 4부의 추론과 손을 맞잡고 있다. "사실 목록을 뒤져 어떤 사실이 거기 있는지 찾는 일" — 추론의 한 동작이 바로 이것이기 때문이다. 몇 줄짜리 LISP 함수 안에 이미 지식 탐색의 씨앗이 웅크리고 있는 셈이다.

## 직접 해보기: 동물 분류 (의미망의 맛보기)

14장의 의미망을 아주 작게 흉내 내보자. "무엇이 무엇인가"를 리스트에 담고, 상속의 길을 따라 더듬어 내려가는 것이다.

```lisp
(defun 동물인가 (x)
  (cond ((equal x '참새) t)
        ((equal x '독수리) t)
        ((equal x '고래) t)
        (t nil)))

(동물인가 '참새)   ; → t
(동물인가 '돌멩이) ; → nil
```

여기서 손을 멈추지 말자. "새인가?", "날 수 있나?" 같은 물음을 덧대어 보고, 펭귄처럼 규칙을 비집고 나오는 예외를 어떻게 다룰지(14-01의 기본값) 직접 씨름해 보라. 그 씨름이 곧 지식 표현을 머리가 아닌 몸으로 익히는 과정이다.

## 마무리

작은 예제들이지만, 그 안에는 큰 것들이 접혀 들어 있다. 재귀는 탐색의 뼈대였고, 리스트 검색은 추론의 씨앗이었으며, 분류는 지식 표현의 첫 발이었다. 이것들을 직접 짜본 손은, 앞서 읽었던 개념들을 비로소 손끝으로 안다. 그리고 저 너머에는 또 하나의 고전이 기다린다. 사실과 규칙을 적어두면 스스로 답을 길어 올리는 언어, 논리로 프로그래밍하는 Prolog다.

### 정리

- 리스트 뒤집기, 멤버 찾기, 분류를 재귀로 직접 구현해 보았다.
- 작은 함수 안에 탐색(재귀)·추론(검색)·지식 표현(분류)의 씨앗이 들어 있다.
- 핵심은 읽기가 아니라 직접 짜보고 머릿속으로 돌려보기 — 그래야 체득된다.
