# 『인공지능의 기초』 도식 스타일 가이드 (Drawing Style)

모든 그림은 **직접 그린 원본 SVG**로 만든다(크롤 이미지 직접 사용 금지 — 저작권).
한 권 전체가 한 손에서 나온 듯 보이도록 아래 시각 언어를 통일한다.

## 톤
차분하고 단정한 '교과서 + 손그림' 사이의 라인 다이어그램. 색은 절제(잉크 + 따뜻한 강조 1색 + 차가운 보조 1색).

## 색 팔레트
- 배경(패널): `#FBF7EF` (따뜻한 종이색), 테두리 `#E7DFCB`
- 잉크(선·글자): `#2A2A2A`
- 강조(따뜻): `#B5651D` (테라코타) — 핵심 요소·강조
- 보조(차가움): `#3B6EA5` (차분한 파랑) — 보조 요소·데이터
- 보조 면1: `#F3E7D6` / 보조 면2: `#E9EEF5`
- 흐린 글자(주석): `#7A7268`

## 형태 규칙
- 노드: 모서리 둥근 사각형(rx=8) 또는 원, 채움 `#FFFFFF`, 선 `#2A2A2A` 1.6px
- 화살표: 잉크색 1.6px + 통일된 화살촉(marker)
- 글꼴: `'Helvetica Neue', Arial, 'AppleSDGothicNeo', sans-serif`. 제목 13~15px bold, 라벨 12px, 주석 11px italic `#7A7268`
- 모든 그림은 좌상단에 작은 캡션 영역 없이, 본문 마크다운 캡션(`![설명](...)`)으로 설명한다
- viewBox 가로 720 기준(가독성), 배경 패널 rounded(rx=14)

## 파일 규칙
- 위치: `pages/assets/*.svg`, 페이지에서 `![설명](assets/이름.svg)`로 참조
- 이름: 영문 소문자-하이픈 (예: `neuron.svg`, `bfs-tree.svg`)
- 크롤 원본은 *참고만* 하고 형태는 새로 그린다
