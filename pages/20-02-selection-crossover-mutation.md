# 20-02. 선택·교차·돌연변이

축사 안, 목동은 가장 튼튼한 양 몇 마리만 골라 다음 봄의 새끼를 맡긴다. 약한 것은 무리에서 빠지고, 강한 것끼리 짝을 짓고, 이따금 누구도 예상 못한 무늬의 새끼가 태어난다. 수천 년을 이어 온 이 단순한 손놀림이 가축의 몸을, 곡식의 알을, 결국 한 종의 미래를 빚어 왔다. 유전 알고리즘(20-01)이 후보 해들의 집단을 진화시킬 때 하는 일도 정확히 이것이다. 그 진화를 실제로 굴리는 손놀림은 세 가지뿐이다 — **선택·교차·돌연변이**. 이 셋의 반복이 곧 유전 알고리즘의 전부라 해도 좋다.

## 한 세대의 흐름

한 세대는 다음 순환으로 흘러간다.

```
초기 개체군(무작위) 생성
  └▶ ① 적합도 평가
      └▶ ② 선택 (잘난 것을 고름)
          └▶ ③ 교차 (섞어 자식 생성)
              └▶ ④ 돌연변이 (가끔 변형)
                  └▶ 새 세대 → 다시 ①  (목표 도달까지)
```

## ① 선택 (selection): 잘난 것을 남긴다

목동이 튼튼한 양을 고르듯, 적합도가 높은 개체일수록 **부모로 뽑힐 확률이 높게** 한다. 자연선택의 '적자생존'에 해당하는 자리다. 다만 무조건 1등만 골라 짝지으면 무리는 곧 한 핏줄로 좁아지고, 다양성이 사라진 채 한곳에 갇혀 버린다 — 조기 수렴이다. 그래서 *적당히 무작위성을 섞어* 덜 좋은 개체에게도 기회를 준다. 결국 **탐색(새로운 시도)과 활용(좋은 것 강화)의 균형**이 모든 것을 가른다.

## ② 교차 (crossover): 섞어서 자식을 만든다

뽑힌 두 부모의 유전자를 **잘라 섞어** 자식을 만든다.

```
부모A: 1 1 0 | 1 0 1
부모B: 0 1 1 | 0 0 0
─────────────────────
자식 : 1 1 0 | 0 0 0   (앞은 A, 뒤는 B)
```

교차의 묘미는 **좋은 부분끼리의 결합**에 있다. A의 뛰어난 앞부분과 B의 뛰어난 뒷부분이 한 몸에서 만나면, 부모 어느 쪽보다 나은 자식이 태어날 수 있다. 유전 알고리즘을 앞으로 미는 핵심 동력이 바로 여기다.

## ③ 돌연변이 (mutation): 가끔 바꾼다

낮은 확률로 유전자 일부를 **무작위로 바꾼다**(예: 비트 하나 뒤집기).

```
자식 : 1 1 0 0 0 0  →  1 1 0 0 1 0   (한 자리 변이)
```

작아 보이지만 결정적인 손길이다. 교차는 *기존 개체군에 있던 조각들*을 다시 짜맞출 뿐이라, 무리가 죄다 비슷해지고 나면 더는 새로울 게 없어 멈춘다. 돌연변이는 그 막다른 골목에 **완전히 새로운 가능성**을 슬쩍 떨어뜨려, 5장에서 본 *지역 최솟값*에 갇히는 것을 막아 준다.

## 균형의 예술

유전 알고리즘을 잘 다룬다는 것은 결국 **균형 맞추기**다. 선택압이 너무 세면 다양성을 잃고 일찍 갇히고, 돌연변이가 너무 많으면 그저 무작위 탐색이 되어 끝내 수렴하지 못한다. 두 힘이 적당히 맞물리는 자리에서야 비로소, 세대를 거듭할수록 점점 나은 해로 무리 전체가 모여든다.

## 5부 속 유전 알고리즘의 자리

유전 알고리즘은 신경망과는 전혀 다른 길로 '학습'에 다가간다 — 미분(경사 하강)이 아니라 *진화*로다. 그래서 미분이 어려운 문제, 이를테면 구조 설계나 게임 전략, 일정 최적화 같은 곳에서 특히 쓸모가 크다. 그리고 이 진화의 발상은 21장 **인공생명**에서 디지털 생태계로까지 뻗어 나간다.

---

### 정리

- 유전 알고리즘 = **선택·교차·돌연변이**의 세대 반복.
- **선택**(잘난 것 남김)·**교차**(좋은 부분 결합)·**돌연변이**(새 가능성 주입, 지역 최솟값 탈출).
- 핵심은 **탐색과 활용의 균형** — 미분이 어려운 문제에 강하다.

### 생각해보기

- 교차는 "좋은 것끼리 섞으면 더 좋아진다"고 가정한다. 늘 그럴까. 두 좋은 해를 섞었더니 오히려 나빠지는 경우를 떠올려 보라 — 그래서 왜 *여러 자식*을 만들고 *선택*이 필요한 걸까.
