# 인공지능의 기초 (Fundamental of AI)

> **트렌드가 아니라 토대를.** 가장 새로운 모델이 아니라, 인공지능이라는 분야가 어떤 질문에서 출발했고 어떤 개념 위에 세워졌는지를 처음부터 차근차근 다지는 책.

새 모델이 나올 때마다 처음부터 다시 배우는 기분이 든다면, 그것은 흐름만 쫓았을 뿐 그 아래의 바닥을 딛지 못했기 때문입니다. 이 책은 그 바닥을 다집니다. 탐색·논리·추론·지식 표현·학습·신경망·언어 — 수십 년 전에 다듬어진 이 개념들은 오늘의 거대한 모델 안에서도 여전히 살아 숨 쉬고 있습니다. 표면의 이름만 바뀌었을 뿐입니다.

## 이 책이 지향하는 것

- **트렌드에 휘둘리지 않기** — 오늘의 유행어가 아니라 10년 뒤에도 유효할 개념을.
- **처음부터 차근차근** — 수학·논리·사람의 사고와 뇌에서 시작해 탐색·추론·학습으로. 건너뛰지 않습니다.
- **소설처럼 읽히되, 펀더멘털이 쌓이게** — 장면과 이야기로 열고, 개념은 그 끝에서 자연스럽게 도착합니다.
- **만들 수 있어야 안다** — 읽고 끄덕이는 데서 멈추지 않고, LISP·Prolog로 직접 손을 움직여 확인합니다.

## 누구를 위한 책인가

- 최신 기술을 다뤄 봤지만 **기초가 비어 있다고 느끼는** 사람
- 인공지능을 유행이 아니라 **하나의 학문으로** 제대로 공부하고 싶은 사람
- 빠른 답보다 **단단한 실력**을 원하는 사람

## 구성 (8부 · 31장 + 부록)

1. **인공지능이란 무엇인가** — 지능·튜링 테스트·역사·철학·분야 지도
2. **기초 체력** — 수학 · 논리 · 인지심리학 · 뇌와 신경 · 계산과 알고리즘
3. **탐색과 문제해결** — 상태공간 · BFS/DFS · 휴리스틱(A*) · 게임 트리
4. **지식 표현과 추론** — 의미망·규칙·온톨로지 · 추론 · 전문가 시스템 · 퍼지
5. **학습하는 기계** — 기계학습 · 신경망(CNN·딥러닝) · 유전 알고리즘 · 인공생명 · 패턴 인식
6. **언어와 지각** — 자연어 처리 · 지능형 에이전트 · 로봇공학
7. **고전 AI의 도구** — LISP · Prolog (직접 코딩)
8. **인공지능의 지평** — 인지과학 · 인접 과학(제어·카오스·복잡계) · 사회와 경제 · 문화와 예술(SF·영화)
- **부록** — 인공지능의 선구자 사전 · 용어집
