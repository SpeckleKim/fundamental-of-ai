# 문체 비교 샘플 (Style Samples)

같은 절(05-01 선형대수)을 두 가지 문체로 써서 비교하는 폴더입니다.
책 본문(`pages/`)은 **v1(교과서체)**를 유지하고, 여기서 두 방향을 나란히 검토합니다.

- **`05-01-v1-textbook.md`** — 기존 톤. `~습니다`체, 헤더·불릿·정리 중심. 명료한 교과서.
- **`05-01-v2-novel.md`** — 새 톤. 장면으로 열고 산문으로 흐르는 `~다`체. 소설처럼 읽힘.

> 결정을 위한 메모: v2는 몰입감이 크지만 문체(`~다`)가 기존 108개 절과 달라 전권 통일이 필요합니다.
> 두 버전을 읽어 보고 어느 방향(또는 절충: 장면+산문은 채택하되 `~습니다` 유지)으로 갈지 정하면 됩니다.
